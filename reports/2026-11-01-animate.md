# List navigation motion — 2026-11-01

Released in Pencils 0.20.125 on 2026-11-01. Impeccable animate pass in Operate/Read mode, preserving the compact existing interface.

## Motion thesis

- **Focal moment:** opening the shared document or board list from its view tab. Its leftward origin explains the panel's relationship to the open document or board.
- **Continuity:** a 24px reveal with opacity over 180ms, using a decelerating curve; dismissal takes at most 120ms. Reversing direction uses the current transition state. A rebuilt page with the list already open does not replay the entrance.
- **Feedback:** input and keyboard focus follow the logical open/closed state immediately. The short exit never leaves invisible interactive controls over the page. Closing the touch Documents tray returns focus to the active tab when the original button cannot receive it.
- **Budget:** one panel, only on deliberate navigation. No per-row stagger, layout animation, animated blur, new library, JavaScript animation loop or changes to board-object transitions.

Reduced motion shows or hides the panel immediately. Browsers without discrete display transitions also dismiss immediately; the installed Firefox used this fallback. A navigation that rebuilds the page may remove the outgoing panel immediately rather than delaying the choice.
